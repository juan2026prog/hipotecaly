# SEGURIDAD DE FIRMA DIGITAL (LEY N° 18.600) — HIPOTECALY

## 1. Marco Jurídico Uruguayo
Cumplimiento con Ley 18.600 de Documento y Firma Electrónica Avanzada.

## 2. Cadena de Integridad (SHA-256)
- Registro de hash previo a la firma en generated_documents.
- Firma mediante proveedores acreditados (Firma.gub.uy / UCE).
- Verificación del nuevo hash resultante con evidencia forense inmutable.
