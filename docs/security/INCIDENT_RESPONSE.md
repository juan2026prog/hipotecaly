# PLAN DE RESPUESTA A INCIDENTES DE SEGURIDAD — HIPOTECALY

## 1. Fases del Procedimiento
1. DETECTED: Anomalía detectada vía security_events, alertas de rate limit o reporte.
2. TRIAGED: Clasificación de severidad (CRITICAL, HIGH, MEDIUM, LOW).
3. CONTAINED: Revocación de API Keys, corte temporal de IA o revocación de sesiones.
4. ERADICATED: Corrección de vulnerabilidad y actualización de migraciones.
5. RECOVERED: Restauración de servicios y verificación de integridad SHA-256.
6. CLOSED: Informe forense asentado en security_events.

## 2. Notificación Legal
Notificación formal a la URCDP (AGESIC) dentro de los plazos legales en caso de impacto sobre datos personales.
